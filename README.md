# Biglietteria Distribuita

Sistema di biglietteria distribuita basato su blockchain Hyperledger Besu.

## Avvio del progetto

Dopo aver clonato il repository, avviare tutti i servizi tramite Docker Compose:

```bash
docker compose up -d
```

Al termine dell'avvio, i container dei vari servizi saranno eseguiti in background.
